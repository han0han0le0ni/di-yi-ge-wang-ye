给 DSH 的长期人格与记忆

TypeScript 写的「大脑」插件（v0.8.0）：人格分层、性格演化、长期记忆、运行时状态、技能反射与安全降级，表现层交给桌宠端。 记忆跟着角色走，不跟着会话走——换窗口、换工作区，关系和经历都还在。

  • 人格：L1–L5 分层，L1–L4 慢写回、L5 不写回；动机双通路（阈值偏移 + 方向舵乘子），外加熟悉度倒 U 和失败熔断。
  • 记忆：摘要层 + 全文层双路检索，SQLite FTS5 trigram 配 Dice 相似度，五维加权并支持一二跳联想；删除可恢复，主动开口默认关闭。
  • 节奏：hold 是攒劲而不是丢弃，思念饱和度按 idle/(idle+180min) 算——攒够一次才真的开口，文案是模板，不冒充模型生成。
  • 边界：三档安全降级；本机 HTTP 端点改用 32 字节令牌鉴权（0600 权限），只有 /health 免令牌。
  • 落地：10 个 .cs 加 info.lps 组成 VPet MOD，5 个 DLL；游戏侧 11074、注入预算 3000 tokens；309 项测试全绿，外部连接通了 4/7。

一个能离线运行的手机角色扮演应用

Kotlin + Jetpack Compose 写的安卓应用（v1.2.8）：角色、会话、消息、记忆全部存在本机 Room 数据库， API Key 走 Android Keystore。没有服务端、没有账号，填一个自己的模型 Key 就能开始。

  • 对话：单角色与多角色群聊，流式输出可随时打断；消息可编辑、重生成、从这里继续；线性截断配内存撤销栈，一键还原，不做分支树。
  • 角色：酒馆卡 JSON / PNG 导入，兼容 V1 / V2 / V3 和 character_book 世界书；支持 {{char}}、{{user}}、{{date}} 等宏，世界书按关键词触发并按优先级分预算。
  • 记忆：L0–L5 六层，每 8 轮或 10 分钟后台抽取一次，走 ADD / UPDATE / DELETE / NOOP 对账；FTS5 逐字分词配 bm25 排序粗筛，每条记忆都能追到来源消息。
  • 工程：Room 2.8.5 + KSP，SQLite 用 sqlite-bundled 自带（系统版没有 FTS5），网络 OkHttp 5 + 手写 SSE；APK 实测 7.34 MB，其中 4.98 MB 是四个 ABI 的原生库。
  • 隐私：数据只在本机，卸载即丢失，所以要自己定期备份；Key 不写日志、不进备份明文，除你自己配的模型接口外不外发数据。
  • 限制：角色卡只导入不导出；alternate_greetings / use_regex / secondary_keys 会被忽略；群聊每轮需要手动指定发言人。

把本机模型变成局域网里的 OpenAI 接口

Go + Wails 写的单文件程序：选一个本地 GGUF，它自己拼启动参数、拉起 llama-server，再对外开一个 OpenAI 兼容网关。手机只改 Base URL、Key 留空就能用，既不用装 Ollama，也不用敲命令行。

  • 参数：87 个参数只在 internal/params/defs.go 声明一次，UI、校验、Schema、下发全由注册表生成；n_gpu_layers / n_ctx / cache_type_* 这类加载级参数任何请求都改不动，界面上直接标锁。
  • 推荐：读显存和 GGUF 头部之后用纯算术算层数、上下文、KV 缓存量化，每一项都能展开看代入的算式，例如「4.7GB ÷ 32 层 = 147MB/层 → 收敛到 31 层」。
  • 模板：转发前把 system 消息提到首位、按模型名自动套模板、内置模板库加「通用宽松」兜底，再把 Jinja 报错翻成中文——手机客户端最常见的模板报错基本消失。
  • 接入：网关只有 :8080，支持 SSE 流式 / NDJSON / 纯文本 / 单次 JSON；管理台和端口池都只绑回环，局域网只暴露推理接口。实测在 RTX 5060 8GB 上自动选中 cuda12 运行时。
  • 限制：无鉴权、无来源过滤、明文 HTTP，定位就是家里自己用；一次只跑一个模型（换模型等于重启子进程）；不下载模型也不带运行时，llama-server.exe 要自己放。

把 ComfyUI 接进 DSH 的侧边栏

DSH 插件：Host 注册 HTTP 路由，Client 注册侧边栏「ComfyUI 工作台」，Agent 注册工具。 面板里能看显卡与队列、选工作流出图、盯进度、管本地图库，画布还能和 ComfyUI 原生界面双向同步。

  • 状态：GPU 优先读 nvidia-smi 利用率，没 N 卡或取不到时退回显存占用；CPU 用两次采样差值算使用率，取不到时退回内存占用；ComfyUI 在线状态与队列每 4 秒刷新。
  • 画布：按磁盘上的工作流 JSON 画出原生节点图，滚轮缩放、拖拽平移、框选删除、改控件回车写盘；改动会经桥接扩展实时广播到 ComfyUI，ComfyUI 保存工作流后 3 秒内自动回读。
  • Agent：9 个工具里 comfy_desk_draw 会等生成完成并把图片以 markdown 回传对话；不需要说工具名和工作流名——按画面描述、中英文、模型质量（SDXL > Chroma > Qwen > SD15）自动挑工作流。
  • 工程：Host 只用 Node 内置模块，Client 只用 react，0 第三方依赖；自检覆盖 48 条路由、23 个客户端请求路径、9 个工具，本机 ComfyUI 0.46 实测在线。
  • 限制：bypass 节点不会自动重连；画布内不能新建节点或重连连线；进度是 HTTP 轮询不是 WebSocket；双向同步需要重启 ComfyUI 加载桥接，两边同时改会互相覆盖。
